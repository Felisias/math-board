# Доска для уроков математики

Онлайн-доска, на которой учитель и ученики рисуют вместе в реальном времени, разговаривают голосом и переписываются в чате. Создаёте доску, отправляете ссылку, ученик открывает её в браузере. Регистрация не нужна.

Доску можно запустить тремя способами:

| Способ | Что нужно | Когда удобно |
|---|---|---|
| **Хостинг (Render)** | репозиторий на GitHub | ссылка постоянная, компьютер может быть выключен |
| **Приложение для Windows** | установить один файл | свой компьютер вместо сервера, доски хранятся у вас |
| **Запуск из папки** | Node.js | то же самое без установки приложения |

## Что умеет

**Рисование и фигуры**
- Карандаш, выделитель, ластик, лазерная указка
- Отрезок, стрелка, прямоугольник, окружность, треугольник, ломаная и многоугольник
- Ровные фигуры от руки: нарисуйте линию, круг или прямоугольник и задержите руку на полсекунды
- Пунктир, заливка, привязка к клеткам

**Математика**
- Координатная плоскость любого размера с осями, делениями и настройкой единичного отрезка
- Графики функций: пишете `x^2 - 4x + 3`, и график строится
- Точки (с подписями A, B, C…) и плавная кривая, проходящая ровно через точки
- Формулы простым вводом: `x^2/3`, `sqrt(x+1)`, `(a+b)/(a-b)`. LaTeX тоже понимается

**Правка**
- У фигур тянется каждый угол, у отрезков — концы, у кривых — их точки
- Панель над выделенным: толщина, пунктир, заливка, порядок слоёв, закрепление, копия, удаление
- Копирование и вставка (в том числе между досками), Alt+перетаскивание, сдвиг стрелками
- Отмена и повтор

**Урок**
- Блокноты и страницы с анимированным выбором
- Голосовая связь и чат
- «Следить за экраном»: нажмите на кружок участника, и ваш экран повторяет его
- «Все ко мне»: переносит всех туда, куда смотрите вы
- Импорт PDF: каждая страница становится страницей доски, поверх можно писать
- Картинки: кнопкой, вставкой из буфера или перетаскиванием
- Светлая и тёмная тема, своя у каждого участника
- Печать в PDF, скачивание доски файлом

Список горячих клавиш открывается на доске клавишей `?` или через меню «⋯».

## Способ 1. Хостинг на Render

1. Загрузите файлы проекта в репозиторий на GitHub.
2. На [render.com](https://render.com) нажмите **New → Web Service** и выберите репозиторий.
3. Укажите **Build Command:** `npm install`, **Start Command:** `node server.js`, **Instance Type:** Free.
4. Нажмите **Deploy**. Когда загорится **Live**, сверху появится адрес доски.

Каждое изменение на GitHub Render выкладывает сам.

На бесплатном тарифе сервер засыпает через 15 минут без посетителей (первое открытие потом занимает до минуты), а диск стирается при перезапуске. Доска при этом не теряется: копия хранится в браузере у участников и восстанавливается сама.

## Способ 2. Приложение для Windows

Приложение запускает доску прямо на вашем компьютере: сервер не нужен, доски лежат у вас на диске и не пропадают.

1. Откройте в репозитории раздел **Releases**, выпуск «Приложение для Windows», и скачайте `Doska-Setup.exe` (установщик) или `Doska-Portable.exe` (запускается без установки).
2. При первом запуске Windows может показать предупреждение SmartScreen, потому что приложение не подписано. Нажмите «Подробнее» → «Выполнить в любом случае».
3. Создайте доску и нажмите **«Пригласить»**.

Приложение пересобирается само при каждом изменении доски на GitHub (вкладка **Actions**, сборка занимает около 5 минут), и файлы в Releases обновляются. Чтобы получить новую версию, скачайте файл заново.

## Способ 3. Запуск из папки

1. Установите [Node.js](https://nodejs.org) (версия LTS).
2. Скачайте проект и запустите файл **«Запустить доску.bat»**. Доска откроется в браузере.

Вручную то же самое делается так:

```
npm install
node server.js --open
```

## Как позвать учеников, если доска запущена на вашем компьютере

Кнопка **«Пригласить»** в этом режиме показывает два варианта.

**Через интернет.** Кнопка «Включить» создаёт временный защищённый адрес (туннель), который ведёт на ваш компьютер. Первый раз скачивается небольшая программа-туннель. Адрес временный и после перезапуска меняется.

- Основной вариант работает через Cloudflare. В России многие провайдеры замедляют Cloudflare, поэтому у учеников из РФ такая ссылка может не открыться.
- Запасной вариант — localhost.run (нужна программа `ssh`, в Windows 10 и 11 она есть).
- Если не подходит ни один, остаётся хостинг (способ 1) или свой сервер.

**В той же сети.** Ссылка вида `http://192.168.x.x:3210/…` работает для устройств в одном Wi-Fi с вами, без интернета. Windows при первом запуске спросит про доступ к сети — разрешите. Голосовая связь по такой ссылке не работает: браузеры разрешают микрофон только на защищённых адресах.

Доска доступна, пока компьютер включён и программа открыта.

## Про голосовую связь

Звук идёт напрямую между браузерами, сервер доски только помогает им найти друг друга. В большинстве домашних сетей это работает сразу.

Если у кого-то не получается соединиться (появится сообщение «Не получилось соединиться голосом»), обычно мешает сеть. Тогда нужен TURN-сервер — посредник для звука. Его адрес задаётся переменной окружения `ICE_SERVERS`, например:

```
[{"urls":"turn:turn.example.com:443?transport=tcp","username":"логин","credential":"пароль"}]
```

На случай проблем со звуком на доске есть чат.

## Из чего сделано

- `server.js` — сервер: раздаёт страницы, синхронизирует доски через WebSocket, передаёт сообщения для голоса и чата
- `tunnel.js` — доступ из интернета при запуске на своём компьютере
- `public/js/board.js` — доска: рисование, объекты, блокноты, синхронизация
- `public/js/extras.js` — чат, приглашение, импорт PDF, подсказки
- `public/js/voice.js` — голосовая связь (WebRTC)
- `public/js/mathparse.js`, `public/js/asciimath.js` — разбор выражений для графиков и простой ввод формул
- `public/vendor` — библиотеки [KaTeX](https://katex.org) (MIT) и [PDF.js](https://mozilla.github.io/pdf.js/) (Apache 2.0), лежат прямо в проекте
- `desktop/` — приложение для компьютера (Electron)
