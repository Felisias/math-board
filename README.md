# Доска для уроков математики

Онлайн-доска, на которой учитель и ученики рисуют вместе в реальном времени и разговаривают голосом. Создаёте доску, отправляете ссылку, ученик открывает её в браузере. Регистрация не нужна.

## Что умеет

- **Рисование:** карандаш, маркер-выделитель, ластик, лазерная указка
- **Фигуры:** отрезок, стрелка (вектор), прямоугольник, окружность или эллипс, треугольник. С Shift получаются ровные фигуры
- **Координатная плоскость:** растягивается на доске как прямоугольник. Внутри оси с делениями, а размер единичного отрезка и положение начала координат настраиваются. Нажмите на плоскость инструментом «График», чтобы построить на ней функцию, или рисуйте на ней сами
- **Фон страницы «Координаты»:** бесконечная координатная плоскость на всю страницу
- **Точки и плавная кривая по точкам:** поставьте точки и кликайте по ним инструментом «Кривая». Линия пройдёт ровно через них, так можно провести параболу или ветвь гиперболы по точкам
- **Текст и формулы:** формулы набираются в LaTeX, есть кнопки-шаблоны
- **Блокноты:** доска делится на блокноты (например, «1 урок», «2 занятие»), в каждом свои страницы. Переключение — через окно с карточками
- **Голосовая связь:** кнопка «Голос» вверху
- **Тема:** светлая и тёмная. У каждого участника своя, цвета на доске подстраиваются сами
- **Картинки:** кнопкой или вставкой из буфера (Ctrl+V)
- **«Все ко мне»:** переносит всех участников туда, куда смотрите вы
- **Сохранение:** печать и сохранение блокнота в PDF, скачивание доски файлом

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| V / H | Выделение / двигать доску (или пробел) |
| P / M / E / K | Карандаш / выделитель / ластик / указка |
| L / A / R / O / Y | Отрезок / стрелка / прямоугольник / окружность / треугольник |
| C | Координатная плоскость |
| D / B | Точка / кривая по точкам (Enter — готово, Esc — отмена) |
| T / F / G | Текст / формула / график |
| PageUp / PageDown | Предыдущая / следующая страница |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+D / Delete | Дублировать / удалить выделенное |

## Как выложить в интернет (GitHub + Render)

1. Загрузите файлы проекта в репозиторий на GitHub.
2. На [render.com](https://render.com) нажмите **New → Web Service** и выберите репозиторий.
3. Укажите **Build Command:** `npm install`, **Start Command:** `node server.js`, **Instance Type:** Free.
4. Нажмите **Deploy**. Когда загорится **Live**, сверху появится адрес доски.

Каждое изменение на GitHub Render выкладывает сам.

## Важно про бесплатный тариф Render

- **Засыпание.** Если 15 минут никто не заходит, сервер засыпает, и первое открытие занимает 30–60 секунд. Откройте доску за пару минут до урока.
- **Диск стирается при перезапуске.** Доска при этом не теряется: копия хранится в браузере у участников и восстанавливается сама. Для важных досок используйте «⋯» → «Скачать доску (файл)».

## Про голосовую связь

Звук идёт напрямую между браузерами, сервер доски только помогает им найти друг друга. В большинстве домашних сетей это работает сразу.

Если у кого-то не получается соединиться (появится сообщение «Не получилось соединиться голосом»), обычно мешает сеть: строгий мобильный оператор или корпоративный интернет. Тогда нужен TURN-сервер — посредник для звука. Его адрес задаётся на Render в разделе **Environment** переменной `ICE_SERVERS`, например:

```
[{"urls":"turn:turn.example.com:443?transport=tcp","username":"логин","credential":"пароль"}]
```

Подойдёт любой TURN-сервис или свой сервер coturn.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```
npm install
npm start
```

Потом откройте http://localhost:3000

## Из чего сделано

- `server.js` — сервер: раздаёт страницы, пересылает изменения между участниками через WebSocket и передаёт служебные сообщения для голосовой связи
- `public/index.html` — главная страница
- `public/board.html`, `public/css/board.css`, `public/js/board.js` — сама доска
- `public/js/voice.js` — голосовая связь (WebRTC)
- `public/js/mathparse.js` — безопасный разбор выражений для графиков
- `public/vendor/katex` — библиотека формул [KaTeX](https://katex.org) (лицензия MIT), лежит прямо в проекте
