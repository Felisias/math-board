# Доска для уроков математики

Онлайн-доска, на которой учитель и ученики рисуют вместе в реальном времени. Создаёте доску, отправляете ссылку, ученик открывает её в браузере. Регистрация не нужна.

## Что умеет

- **Рисование:** карандаш, маркер-выделитель, ластик, лазерная указка
- **Фигуры:** отрезок, стрелка (вектор), прямоугольник, окружность или эллипс, треугольник. С Shift получаются ровные фигуры: квадрат, круг, отрезок под углом кратным 15°
- **Привязка к клеткам:** включается магнитом на панели, фигуры встают точно в узлы сетки
- **Текст и формулы:** формулы набираются в LaTeX, для дробей, корней, степеней, систем и т. д. есть кнопки-шаблоны
- **Графики функций:** пишете `x^2 - 4x + 3`, и график строится на координатной плоскости
- **Фоны страниц:** клетка, координаты, точки, линейка, чистый лист
- **Страницы:** несколько листов в одной доске
- **Картинки:** кнопкой или вставкой из буфера (Ctrl+V)
- **«Все ко мне»:** переносит всех участников туда, куда смотрите вы
- **Работа с объектами:** выделение, перемещение, изменение размера, перекрашивание. Ctrl+D дублирует, Delete удаляет
- **Отмена и повтор:** Ctrl+Z / Ctrl+Y
- **Сохранение:** печать и сохранение в PDF, скачивание доски файлом и открытие из файла
- **Устройства:** работает на компьютере, планшете (со стилусом) и телефоне

### Горячие клавиши

| Клавиша | Инструмент |
|---|---|
| V | Выделение |
| H или пробел | Двигать доску |
| P | Карандаш |
| M | Выделитель |
| E | Ластик |
| K | Указка |
| L / A / R / O / Y | Отрезок / стрелка / прямоугольник / окружность / треугольник |
| T | Текст |
| F | Формула |
| G | График |

Колесо мыши двигает доску, Ctrl + колесо меняет масштаб.

## Как выложить в интернет (GitHub + Render)

### 1. Загрузить код на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **New repository** и придумайте название, например `math-board`. Можно сделать репозиторий приватным (Private). Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите в окно **всё содержимое** папки проекта: файлы `server.js`, `package.json`, `render.yaml`, `README.md`, `.gitignore` и папку `public`.
5. Внизу нажмите **Commit changes**.

### 2. Запустить на Render

1. Зарегистрируйтесь на [render.com](https://render.com). Удобнее всего войти через GitHub.
2. Нажмите **New → Web Service** и выберите свой репозиторий `math-board`. Если его нет в списке, нажмите **Configure account** и дайте Render доступ к репозиторию.
3. Заполните поля:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free
4. Нажмите **Create Web Service** и подождите 2–3 минуты.
5. Сверху появится адрес вида `https://math-board-xxxx.onrender.com`. Это и есть ваша доска.

После этого любое изменение файлов на GitHub автоматически попадёт на сайт.

## Важно про бесплатный тариф Render

- **Засыпание.** Если 15 минут никто не заходит, сервер засыпает. Первое открытие после этого занимает 30–60 секунд. Совет: откройте доску за пару минут до урока. Пока доска открыта, сервер не засыпает.
- **Диск стирается.** При перезапуске сервера сохранённые на нём доски пропадают. Доска при этом не теряется: копия хранится в браузере у каждого участника и восстанавливается сама при следующем подключении. Для важных досок используйте меню «⋯» → **Скачать доску (файл)**.
- **Связь может обрываться.** На бесплатном тарифе соединение иногда рвётся. Доска переподключается сама за секунду, нарисованное не теряется.

Если понадобится надёжнее, есть тариф Starter за $7 в месяц: сервер не засыпает. Ещё вариант — подключить к нему постоянный диск.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```
npm install
npm start
```

Потом откройте http://localhost:3000

## Из чего сделано

- `server.js` — сервер: раздаёт страницы и пересылает изменения между участниками через WebSocket
- `public/index.html` — главная страница
- `public/board.html`, `public/css/board.css`, `public/js/board.js` — сама доска
- `public/js/mathparse.js` — безопасный разбор выражений для графиков
- `public/vendor/katex` — библиотека формул [KaTeX](https://katex.org) (лицензия MIT). Лежит прямо в проекте, поэтому формулы работают без сторонних CDN
